# tulguur2d — ЦДАШ-ын тулгуурын 2D эскиз

«ЭНЕРГОСЕТЬПРОЕКТ»-ийн **«Каталог унифицированных и типовых опор» (1968–1976,
инв. 5713тм-т2)**-ийн бүх тулгуурыг параметрээр 2 хэмжээст DWG зураг болгоно.
`dwgforge` дээр баригдсан.

> **2D elevation drawings of every transmission tower in the 1976 ESP catalogue
> (ВЛ 35–500 kV, steel + reinforced concrete + river-crossing towers).** Built on
> `dwgforge`; renders real AutoCAD DWG through `accoreconsole.exe`.

---

## Юу байгаа вэ

| | Тоо |
|---|---|
| Тулгуурын шифр | **371** |
| Каталогийн лист | 12–82 (71 хуудас) |
| Хүчдэл | 35, 110, 150, 220, 330, 500 кВ |
| Материал | ган (313), төмөр бетон (58) |

Ангилал: завсрын, завсрын өнцгийн, анкер-өнцгийн, төгсгөлийн, салаалах,
их гарамын шилжилтийн, подставка.

Силуэтийн 7 хэв — тус бүр өөрийн зурагчтай:

| Хэв | Жишээ |
|---|---|
| `сүлжээ` свободностоящая решётчатая | П110-1, У220-2 |
| `оттяжкатай` | П220-1, ПС110-11 |
| `портал` | ПВ110-9, П330-9 |
| `портал-татлага` ВЛ 500 кВ | ПБ1…ПБ5, ПУБ-2 |
| `шон` төмөр бетон | ПБ35-1, ПБ110-3 |
| `хос шон` | ПВС-500, ПБ220-2 |
| `гурван шон` | У1, УБМ-17, К330-2 |

Зураг бүрд: бие, сүлжээ, траверс, тросостойк, оттяжка, газрын шугам, нийт
өндөр/доод траверсын өндөр/суурийн өргөн/траверсын гарын хэмжээс, доор нь
паспорт (масс, монтажийн схем, утас, трос, гололёдын район, каталогийн лист).

## Шаардлага

- **AutoCAD 2026+ эсвэл Civil 3D** — `accoreconsole.exe` түүнтэй хамт ирдэг
- Python 3.12+, [`dwgforge`](https://pypi.org/project/dwgforge/)

Шалгах: `python -m dwgforge doctor`

## Ашиглах

### Команд мөр

```powershell
# Жагсаалт — AutoCAD ХЭРЭГГҮЙ
.\.venv\Scripts\python.exe tulguur2d\tulguur.py --jagsaalt --hutsel 110

# Нэг буюу хэд хэдэн тулгуур
.\.venv\Scripts\python.exe tulguur2d\tulguur.py П110-1 У220-2

# Шүүлтээр (тус тусдаа DWG)
.\.venv\Scripts\python.exe tulguur2d\tulguur.py --hutsel 220 --angilal анкер-өнцгийн

# Бүгдийг нэг хуудсанд, 8 баганаар
.\.venv\Scripts\python.exe tulguur2d\tulguur.py --toim --hutsel 35 --bagana 8

# Каталог бүхэлдээ (371 файл, ~13 минут)
.\.venv\Scripts\python.exe tulguur2d\tulguur.py --buh
```

Гаралт: `tulguur2d/zurag/<шифр>.dwg`. Шифрийн кирилл үсэг файлын нэрэнд латин
болно (`П110-1` → `P110-1.dwg`).

**«түгжээний файл байна» гэж гарвал:** өмнөх ажиллагаа таслагдаад `.dwl`
үлдсэн байна. AutoCAD-д тэр зураг нээлттэй биш бол:

```powershell
.\.venv\Scripts\python.exe tulguur2d\tulguur.py --buh --tugjee-arilgah
```

### Локал вэб GUI

```powershell
.\.venv\Scripts\python.exe tulguur2d\gui.py
```

`http://localhost:8767` — зүүн талд каталогийн жагсаалт, шүүлтүүр, хайлт;
баруун талд паспорт, **Үүсгэх** товч, PNG урьдчилсан зураг (AutoCAD-ын
өөрийнх нь плоттероор). Багц үүсгэх, тойм хуудас, явцын заалт бий.
Сервер зөвхөн `127.0.0.1`-ийг сонсоно — нэвтрэлт байхгүй тул сүлжээнд бүү нээ.

### Python-оос

```python
import sys; sys.path.insert(0, "tulguur2d")
from tulguurdata import katalog
from zurag import barih, bicheh, toim

k = katalog()
t = k.ol("У330-2")
print(t.undur, t.jin, t.shem)          # 33.4 22972 3080тм-т9-2а
bicheh(t, Path("out/U330-2.dwg"))      # нэг DWG
toim(k.shuult(hutsel=330), Path("out/330.dwg"))   # нэг хуудсанд бүгд
dwg = barih(t)                          # dwgforge.Drawing — AutoCAD дуудахгүй
```

## Компанийн стандарт руу тохируулах

Шинэ давхарга, фонт зохиохгүй — **танай зурагт байгааг нь** ашиглана. Гурван алхам:

```powershell
# 1. Танай зурагт юу байгааг харах (давхарга, бичгийн хэв, блок, хэмжээсийн хэв)
.\.venv\Scripts\python.exe tulguur2d\zagvar.py унших "C:\zam\танай.dwg"

# 2. Холбоос үүсгэх -> tulguur2d\zagvar.json
.\.venv\Scripts\python.exe tulguur2d\zagvar.py holboh "C:\zam\танай.dwg"

# 3. Цэвэр үрлэг DWG бэлдэх -> tulguur2d\uram\zagvar-uram.dwg
.\.venv\Scripts\python.exe tulguur2d\zagvar.py uram "C:\zam\танай.dwg"
```

Дараа нь бүх зураг **танай** давхарга, **танай** фонтоор гарна. Юу яаж
холбогдсоныг `zagvar.json`-оос харж, гараар засаж болно:

```json
"bichgiin_hev": "DRAW-2.5",
"huree_block": "ХУУДАС_A3",
"shtamp": { "ner": "ШТАМП_A3", "att": [["ЗУРАГ-НЭР", -87.9, 21.36, 2.0]] },
"hunii_ner": { "inzhener": "", "zursan": "", "shalgasan": "" },
"holbolt": {
  "ТУЛГУУР-БИЕ":        "S-0-1-VNDSEN",
  "ТУЛГУУР-СҮЛЖЭЭ":     "S-0-2-NARIIN",
  "ТУЛГУУР-ОТТЯЖКА":    "S-0-3-DASHED",
  "ГАЗАР":              "S-0-10-HATCH",
  "ТЭНХЛЭГ":            "S-0-6-TENHLEG",
  "ХЭМЖЭЭС":            "S-0-5-HEMJEE",
  "БИЧИГ":              "S-0-4-TEXT"
}
```

Юу яаж ажилладаг вэ:

| Юу | Хэрхэн |
|---|---|
| **Давхарга** | `zagvar.json`-ы холбоосоор нэр солигдоно. Үрлэгт байгаа давхаргын өнгө, шугамын төрөл, зузаан ХЭВЭЭР үлдэнэ (дахин тодорхойлогдохгүй). |
| **Фонт** | Танай `STYLE` (жишээ нь `DRAW-2.5` → `isocpeu_mon.ttf`) TEXT бүрт өгөгдөнө. Кирилл зөв гарна. |
| **Блок** | Үрлэг дотор танай блокууд бүгд байгаа тул нэрээр нь `INSERT` хийж болно ([`oruulga.py`](oruulga.py)). Хүрээ нь **хэмжээгээр** (420×297), штамп нь **атрибуттай + хуудас бүрт орсон** гэдгээрээ танигдана. |
| **Хүний нэр** | `hunii_ner`-т бичнэ (инженер, зурсан, шалгасан). Штампын атрибут болж орно — AutoCAD дээр давхар товшиж засаж болно. |

Эх кодод танай блок, давхарга, ажилтны нэр **байхгүй**: бүгд `zagvar.json`-д,
тэр нь `.gitignore`-т. Файл байхгүй бол апп өөрийн хүрээтэйгээр, штампгүй ажиллана.

Үрлэг нь танай зургийн **хуулбар дээр** үүснэ: model space-ийн entity бүгд
устаж, давхарга/хэв/блок/хэмжээсийн хэв үлдэнэ. Эх файлыг хөндөхгүй.
PURGE хийхгүй — эс тэгвээс хэрэгтэй блокууд устана.

## АЗ хуудас угсрах

Танай "ТОНОГЛОЛЫН ТЕХНИКИЙН ҮЗҮҮЛЭЛТ" зургийн бүтцээр — багана бүр нэг
тулгуур, дөрвөн мөртэй: **план тэмдэг + ПК**, **шифр**, **өндөрлөг**,
**фундаментын план**. Анкер/дундын гэж бүлэглэж, доор нь тайлбар, булангийн
хүснэгт тавина.

```powershell
.\.venv\Scripts\python.exe tulguur2d\husnegt.py У110-2 У110-2+5 У110-2+9 П110-4
.\.venv\Scripts\python.exe tulguur2d\husnegt.py --hutsel 110 --bagana 7
.\.venv\Scripts\python.exe tulguur2d\husnegt.py --hutsel 220 --tsaas A1 --masshtab 300
```

Зураг нь модель орчинд **метрээр 1:1** зурагдана — хэмжээсийн тоо каталогийн
утгатай яг таарна. Хүрээ, бичээс нь цаасны мм-ээр өгөгдөж масштабаар үржинэ,
тиймээс 1:M-ээр хэвлэхэд бичээс яг 2.5 мм гарна. Масштабыг хамгийн өндөр
тулгуураас автоматаар (50…2000-аас) сонгоно.

## Хэмжээсийг засах

Зургийн нэгж нь **метр** (1 нэгж = 1 м).

Хэмжээс хоёр газар байна:

1. `tulguurdata.py` — эх хүснэгт, каталогийн лист тус бүрээр блоклосон.
2. `tulguuruud.json` — үүсгэвэл (`python tulguur2d/tulguurdata.py --json`)
   энэ файл дахь утга `.py` дахь утгыг **дардаг**. Тоог засаад дахин зурахад
   хангалттай, кодод хүрэх шаардлагагүй.

```powershell
.\.venv\Scripts\python.exe tulguur2d\tulguurdata.py          # тойм
.\.venv\Scripts\python.exe tulguur2d\tulguurdata.py --json   # засварлах файл
```

## Хэмжээсийн үнэн байдал — уншаарай

Каталог бол **сканердсан гар зураг**. Түүнээс юуг найдвартай авч болох, юуг
болохгүйг ялгаж бичив:

**Каталогоос шууд авсан (найдвартай):**
шифр · масс (цинкгүй/цинктэй) · монтажийн схемийн дугаар · утас, тросны марк ·
гололёдын район · нэмэлт тэмдэглэл · каталогийн лист · **завсрын опорын доод
траверсын өндөр** (лист 83–90-ийн пролётын хүснэгтийн «Высота до нижней
траверсы») · нийт өндөр, суурийн өргөн, траверсын гарын урт (эскизийн
хэмжээснээс).

**Схемийн шинжтэй (жинхэнэ ажлын зурагт тааруулж засна):**
траверс хоорондын **босоо зай** · сүлжээний раскос, панелийн тоо · тросостойк,
оттяжкын нарийн хэлбэр · биеийн нарийсалтын муруй.

Тиймээс эдгээр зураг нь **эскиз** — каталогийн «Эскиз» баганатай яг адил
зорилготой: сонголт хийх, харьцуулах, тоймын хуудас гаргах. Ажлын зураг болгож
барилга угсралтад шууд өгөх зориулалтгүй; тэр тохиолдолд тухайн опорын
монтажийн схемийг (паспорт дээр бичигдсэн) ашиглана уу.

Бичлэг бүр `batalgaa` талбартай. `False` бол зурагт **«≈ хэмжээс ойролцоо»**
гэж хэвлэгдэнэ.

### English summary

`tulguur2d` turns every tower in the Soviet ESP unified-tower catalogue
(5713тм-т2, 1976) into a parametric 2D DWG elevation: 371 designations across
35–500 kV, steel and reinforced concrete, including river-crossing (переходные)
and end (концевые) towers. Ciphers, masses, mounting-scheme numbers, conductor
and ground-wire grades come verbatim from the catalogue; the lower-traverse
heights come from its span tables. Traverse *spacing* and lattice bracing are
schematic — see the accuracy note above. Data is overridable through
`tulguuruud.json` without touching code.
